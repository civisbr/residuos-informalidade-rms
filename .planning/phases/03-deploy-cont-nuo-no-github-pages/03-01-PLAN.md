## Fronteiras de Confiança

| Fronteira | Descrição |
|-----------|-----------|
| push -> GitHub Actions runner | Código commitado em main é executado pelo runner |
| runner -> GitHub Pages CDN | Artifact empacotado pelo build job é publicado pelo deploy job |

## Registro de Ameaças STRIDE

| Threat ID | Categoria | Componente | Disposição | Plano de Mitigação |
|-----------|-----------|------------|------------|-------------------|
| T-03-01 | Tampering | astral-sh/setup-uv e actions/upload-pages-artifact | mitigate | Usar tags imutáveis de versão completa (v8.2.0, v5.0.0) em vez de tags móveis; reduz superfície de comprometimento silencioso |
| T-03-02 | Elevation of Privilege | Job deploy | mitigate | Environment github-pages mantido — Pages só aceita deploy de branch main com OIDC token (id-token:write); permissions scoped (contents:read, não write) |
| T-03-03 | Information Disclosure | Workflow logs | accept | Sem secrets neste workflow; BUILD_DATE é data pública; pipeline usa apenas dados públicos offline |
| T-03-04 | Denial of Service | Deploys concorrentes | mitigate | concurrency group "pages" com cancel-in-progress:true evita race condition e estado inconsistente do Pages |
| T-03-SC | Tampering | npm/pip installs | accept | Esta fase não instala novos pacotes; uv sync usa lockfile commitado; sem ASSUMED/SUS packages |

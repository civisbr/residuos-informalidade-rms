  <name>Task 1: Ativar GitHub Pages — Source = "GitHub Actions" (D-04)</name>

  <what-built>
    O workflow .github/workflows/build.yml foi finalizado no plano 03-01 e está commitado
    na main. O próximo passo é ativar o Pages nas Settings do repositório — ação no GitHub
    que não é versionável e que cria o environment "github-pages" obrigatório para o job deploy.

    SEM esta ativação, o job deploy falha com "environment 'github-pages' not found" ou
    "HttpError: Not Found" — mesmo com o workflow correto.
  </what-built>

  <how-to-verify>
    Executar os seguintes passos no GitHub:

    1. Abrir o repositório em: https://github.com/civisbr/residuos-informalidade-rms
    2. Clicar em "Settings" (aba no menu superior)
    3. No menu lateral esquerdo, clicar em "Pages"
    4. Na seção "Build and deployment" → campo "Source": selecionar "GitHub Actions"
    5. Clicar em "Save" (se aparecer botão de salvar)

    Verificação pós-ativação:
    - A página Settings → Pages deve exibir a mensagem "Your site is ready to be published" ou
      indicar que o Pages está configurado com Source "GitHub Actions"
    - O environment "github-pages" deve aparecer em Settings → Environments

    Opcional (confirmar deploy ativo): fazer push de um commit vazio na main ou usar
    "Actions → build-and-deploy → Run workflow" (workflow_dispatch) e aguardar o job deploy
    concluir com sucesso. Após o primeiro deploy bem-sucedido, acessar
    https://civisbr.github.io/residuos-informalidade-rms/ deve exibir o painel.
  </how-to-verify>

  <resume-signal>
    Quando o Pages estiver ativado com Source = "GitHub Actions", responda "ativado".
    Se o primeiro deploy já tiver rodado com sucesso, responda "ativado e publicado".
    Se encontrar problema, descreva o erro exibido.
  </resume-signal>

|-----------|-----------|
| Browser -> GitHub Pages CDN | Visitante acessa o painel servido pelo Pages (HTTPS automático) |
| README -> GitHub Actions badge | Badge SVG consumido por qualquer leitor do README |

## Registro de Ameaças STRIDE

| Threat ID | Categoria | Componente | Disposição | Plano de Mitigação |
|-----------|-----------|------------|------------|-------------------|
| T-03-05 | Elevation of Privilege | GitHub Pages environment | mitigate | D-04 ativa proteção do environment github-pages — só main pode fazer deploy; sem bypass por branches de feature |
| T-03-06 | Information Disclosure | README badge | accept | Badge revela que o repositório existe e o status do build — informação pública intencional; sem risco para site estático sem dados privados |
| T-03-07 | Spoofing | URL do painel publicado | accept | Pages serve HTTPS com certificado gerenciado pelo GitHub; sem user input; site estático sem autenticação |
| T-03-SC | Tampering | npm/pip installs | accept | Esta fase não instala pacotes; apenas edita README.md |
</threat_model>

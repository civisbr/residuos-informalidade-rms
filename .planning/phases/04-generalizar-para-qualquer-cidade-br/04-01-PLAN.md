## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI → ibge.refresh() | args.region passado pelo usuário; usado para selecionar a região no YAML |
| ibge.refresh() → API IBGE | chamada de rede a servicodados.ibge.gov.br e apisidra.ibge.gov.br (HTTP público) |
| API IBGE → config/municipios.csv | resposta da API escrita como CSV no repositório |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | ibge.refresh() — args.region usado para selecionar região no YAML | mitigate | Validar que region está presente em regions.yml (via `if region not in regions`) antes de qualquer operação; falha com mensagem amigável, sem path traversal possível (região não vira nome de arquivo neste plano) |
| T-04-02 | Tampering | regions.yml lido com yaml.safe_load | mitigate | yaml.safe_load() já em uso no projeto — nunca yaml.load(); impede execução de código arbitrário via YAML |
| T-04-03 | Denial of Service | httpx.Client sem timeout — chamada SIDRA pode travar | mitigate | httpx.Client(timeout=60) para localidades; httpx.Client(timeout=120) para SIDRA batch (~1.4MB) |
| T-04-04 | Tampering | Dados de API IBGE corrompidos gravados no CSV — campo V não-numérico | mitigate | Condição r.get("V", "").isdigit() antes de int(r["V"]); município com V inválido não recebe populacao (fica None/vazio, flag pendente honesto) |
| T-04-05 | Spoofing | API IBGE retorna nome de município malicioso com caracteres de path | accept | municipios.csv não usa o nome como nome de arquivo; apenas como coluna de texto; risco: baixo |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | Nenhum pacote novo — todas as dependências (httpx, polars, pyyaml, difflib) já estão em pyproject.toml |
</threat_model>

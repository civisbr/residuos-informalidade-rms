| Fronteira | Descrição |
|-----------|-----------|
| API SIDRA (externa) → CSV snapshot | refresh() faz GET em apisidra.ibge.gov.br; resposta não autenticada, pública |
| BigQuery (GCP) → CSV snapshot | refresh() usa ADC do usuário; billing project residuos-github |
| CSV commitado no git → pipeline offline | load() consome CSV da árvore git; é a fonte de verdade do build determinístico |
| CSV de entrada → SCHEMA Polars | Polars valida tipos; campos extras são ignorados; campos faltando ficam null |
